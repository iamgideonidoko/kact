Kact is a keyboard-driven cursor ACTuator. Current backends provide native macOS navigation overlays and Linux X11 shell actions; every supported platform can use the command-first interface.

<div class="home-install">
<Tabs>
  <TabItem label="Release">

```sh
curl --proto '=https' --tlsv1.2 -fsSL https://raw.githubusercontent.com/iamgideonidoko/kact/main/scripts/install.sh | bash # latest release
kact setup
kact status
```

  </TabItem>
  <TabItem label="Source">

```sh
mise install
cargo install --locked --path .
kact setup
kact status
```

  </TabItem>
</Tabs>
</div>

## Platform support

| Platform | Status |
| --- | --- |
| macOS | Native overlays, accessibility targeting, keyboard capture, shell actions, and modified clicks. |
| Linux X11 | Shell-driven pointer actions. Bind commands from the window manager or another shortcut tool. |
| Wayland | Unsupported by the native backend. |
| Windows | Unsupported. |
