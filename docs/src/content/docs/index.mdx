Kact exposes pointer actions through a local daemon and CLI. Use its native macOS navigation overlays, or call commands from shells and keyboard remappers.

```sh
mise install
cargo install --path .
kact start
kact activate grid
```

## Platform support

| Platform | Status |
| --- | --- |
| macOS | Native overlays, accessibility targeting, keyboard capture, shell actions, and modified clicks. |
| Linux X11 | Shell-driven pointer actions. Bind commands from the window manager or another shortcut tool. |
| Wayland | Unsupported by the native backend. |
| Windows | Unsupported. |
