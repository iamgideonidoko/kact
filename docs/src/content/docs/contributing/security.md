---
title: Security
description: Supported versions and private vulnerability reporting.
---

Security fixes apply to the latest unreleased development version until a stable release policy is published.

Do not open a public issue for a vulnerability. Use [GitHub private vulnerability reporting](https://github.com/iamgideonidoko/kact/security/advisories/new) with reproduction steps, the affected version and platform, and impact. The canonical policy is [`SECURITY.md`](https://github.com/iamgideonidoko/kact/blob/main/SECURITY.md).
