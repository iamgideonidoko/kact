# Security policy

## Supported versions

Security fixes are applied to the latest unreleased development version until the first stable release policy is published.

## Reporting a vulnerability

Do not open a public issue. Use [GitHub private vulnerability reporting](https://github.com/iamgideonidoko/kact/security/advisories/new) and include reproduction steps, affected version, platform, and impact. You should receive an acknowledgement within seven days.
