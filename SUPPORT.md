# Support

Start with the [documentation](https://iamgideonidoko.github.io/kact/) and [troubleshooting guide](https://iamgideonidoko.github.io/kact/help/troubleshooting/). For reproducible defects or concrete feature requests, use the corresponding GitHub issue template.
